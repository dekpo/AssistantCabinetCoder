# Cabinet Spike (throw-away)

This folder is the probe of Lot X0. It is **not the product**: it answers from a script, logs structure only (never text) and is deleted at the end of Lot X1b. Its test script is `docs/human-tests/X0-spike.md`; its findings go to `docs/SPIKE-FINDINGS.md`.

Build: `npm run spike:build`. Package: `npm run spike:package` (writes `spike/cabinet-spike-0.0.1.vsix`). Unit tests: `npm run spike:test`.
